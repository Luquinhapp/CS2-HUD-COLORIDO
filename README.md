# CS2-HUD-COLORIDO
CS2 Dynamic HUD Color Changer 🎨
Uma configuração simples em .cfg para o Counter-Strike 2 que altera dinamicamente a cor do HUD automaticamente enquanto você joga (movimentação e ações básicas).

O que este script faz?
O script utiliza um sistema de aliens e loops de comandos atrelados às teclas principais do jogo. Cada vez que você se movimenta ou executa uma ação básica, a cor do seu HUD cicla para o próximo tom disponível no jogo:
Teclas de Movimentação (W, A, S, D): Mudam a cor do HUD a cada passo dado.   
Disparo (Mouse1): Altera a cor do HUD ao atirar.   
Rolagem do Mouse (Wheel Up / Wheel Down): Alterna a cor ao utilizar o pulo na roda do mouse.

Para baixar copie o arquivo hud_colorido.cfg (ou o nome que preferir).   
Cole o arquivo no diretório de configurações do CS2, geralmente localizado em:

\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg

Depois disso o proximo passo:

Na sua biblioteca da steam vai em propriedades e depois opçoes de inicialização e coloque o seguinte comando: exec hud_colorido

Pronto, apos isso seu cs vai estar com o hud trocando de cor RGB.

Caso queira mudar algo na cfg sinta se avontade para mudar os atalhos com as binds no qual voce mais gosta.

Resposta: NAO, ja usei por varias horas ela e em varias contas diferentes e nunca aconteceu nada, o motivo e o seguinte:

como DLL ou alteraçao da memoria do jogo (no caso os cheats), outro motivo que e bem obvio, a cfg so deixa o hud colorido e nao tras nenhuma vantagem no competitivo.
